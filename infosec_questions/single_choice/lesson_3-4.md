# Information Security MCQs — Lesson 3 & 4 (Single Choice)

Source: `lesson 3 & 4.pdf` (Information Security for Server and Client Systems)

**Format:** Choose the single best answer (A-E).

**Mix:** Q1-Q75 are application/understanding-focused; Q76-Q100 are core knowledge checks.

---
## Q1. A company discovers its web server exposes folder contents to anyone. Which issue is most directly indicated?

- A) Directory listing exposure
- B) Buffer overflow vulnerability
- C) Cross-site request forgery
- D) DNS cache poisoning
- E) Session fixation

**Answer:** A

**Explanation:** Automatic directory listing can disclose files and compromise secrecy.

---

## Q2. An attacker tries thousands of common words against a login form until one succeeds. This is best described as a:

- A) Dictionary attack
- B) Brute-force rainbow table attack
- C) Credential stuffing attack
- D) Password spraying attack
- E) Keylogging attack

**Answer:** A

**Explanation:** Dictionary attacks cycle through likely words/passwords from a list.

---

## Q3. An employee opens a macro-enabled document from an unknown sender and malware executes. This is most consistent with a:

- A) Macro virus
- B) Boot sector virus
- C) Polymorphic worm
- D) Rootkit
- E) Logic bomb

**Answer:** A

**Explanation:** A macro virus is embedded in a document/file macro and runs when the file is opened.
