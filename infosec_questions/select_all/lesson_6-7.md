## Q1. The board asks for a security program aligned with business objectives and regulations. This requires:

- A) IT security governance
- B) Policies and oversight
- C) Roles, accountability, and metrics
- D) Only technical tools
- E) IT-only decision making

**Answer:** A, B, C

**Explanation:** Governance directs and controls security in alignment with business and regulations.
